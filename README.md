# Tiny Wastelands Player Reference

This is a static HTML conversion of the supplied Markdown source files. Internal Obsidian-style links (`[[Page]]`, `[[Page#Heading]]`) have been converted to working links between HTML pages and section anchors.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

The site is static and needs no build step. The source files referenced images such as `CrazyIMG.png`, but those image files were not included in the supplied set; placeholders are shown where needed.
